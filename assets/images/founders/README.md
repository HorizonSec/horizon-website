# Founders Images

This directory contains profile photos and images of the HorizonSec Project founders.

## File Naming Convention

Please use the following naming convention for founder images:
- `founder-[lastname]-[firstname].jpg` (e.g., `founder-smith-john.jpg`)
- `founder-[lastname]-[firstname]-headshot.jpg` for formal headshots
- `founder-[lastname]-[firstname]-casual.jpg` for casual photos

## Image Specifications

- **Format**: JPG or PNG preferred
- **Size**: Maximum 2MB per image
- **Dimensions**: 
  - Headshots: 400x400px (square) or 400x500px (portrait)
  - Full photos: 800x600px maximum
- **Quality**: High resolution, well-lit, professional appearance

## Usage

These images are used in:
- About page team section
- Leadership/founder profiles
- Press kit materials
- Social media profiles
